# InternBridge - Smart Internship Platform Prototype

## 🚀 Overview
InternBridge is a comprehensive frontend prototype for an innovative internship platform that addresses key challenges in the internship ecosystem. This prototype incorporates cutting-edge features including AI-powered recommendations, blockchain certificate verification, and inclusive access solutions.

## 🎯 Key Features

### 1. AI-based Internship Recommendation Engine
- **Smart Matching**: Analyzes student skills, courses, and interests
- **Dynamic Recommendations**: Real-time matching with available internships
- **Example**: B.Sc. CS student with Python skills → ML internship recommendations
- **Match Percentage**: Visual indicator showing compatibility

### 2. Blockchain-based Certificate Verification
- **Tamper-Proof**: Certificates stored on blockchain for authenticity
- **Instant Verification**: Real-time certificate validation
- **Global Access**: Verify from anywhere in the world
- **Anti-Fraud**: Prevents fake certificates and credential mills

### 3. Rural Access & Inclusivity
- **WhatsApp Integration**: Apply and track via WhatsApp for users without smartphones
- **Offline Mode**: Data sync when internet becomes available
- **IVR Support**: Voice call system for status updates
- **SMS Notifications**: Updates via text messages

### 4. Skill-to-Internship Bridge Courses
- **Micro-Learning**: 15-20 minute modules
- **Industry-Ready Skills**: Resume writing, professional communication, Excel basics
- **Progress Tracking**: Monitor completion and performance
- **Certificate Rewards**: Earn credentials upon completion

### 5. Mentorship & Live Tracking Dashboard
- **Faculty Dashboard**: Real-time student monitoring
- **Progress Visualization**: Visual progress bars and status indicators
- **Industry Mentor Integration**: Direct feedback and remarks system
- **Performance Analytics**: Completion rates and engagement metrics

### 6. Internship Marketplace (Swiggy Model)
- **Gig-Based System**: Short, medium, and long-term opportunities
- **Points/Coins System**: Gamified experience with rewards
- **Easy Application**: One-click apply functionality
- **Category Filters**: Filter by technology, duration, and type

## 🛠️ Technical Stack
- **HTML5**: Semantic structure and accessibility
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript (ES6+)**: Interactive functionality and dynamic content
- **Font Awesome**: Icons for better UX
- **CSS Grid & Flexbox**: Responsive layout system

## 🚀 How to Run

### Method 1: Direct File Opening
1. Navigate to the project directory
2. Double-click `index.html` to open in your browser

### Method 2: Local Server (Recommended)
```bash
# Using Python (if installed)
cd internship-platform-prototype
python -m http.server 8000
# Open http://localhost:8000 in your browser

# Using Node.js (if installed)
npx serve .
# Follow the provided URL
```

### Method 3: Live Server Extension
1. Open the project folder in VS Code
2. Install "Live Server" extension
3. Right-click `index.html` and select "Open with Live Server"
